## 📦 Installing

**Steam Workshop (recommended):** open a mod's Workshop page above and hit **Subscribe**. The CK3 launcher picks it up automatically.

**Manually from GitHub:**

1. Clone or download the mod's repo.
2. Put the folder in your CK3 mod directory:
   - **Windows:** `Documents\Paradox Interactive\Crusader Kings III\mod`
   - **macOS:** `~/Documents/Paradox Interactive/Crusader Kings III/mod`
   - **Linux:** `~/.local/share/Paradox Interactive/Crusader Kings III/mod`
3. Add a `.mod` file next to the folder whose contents are the repo's `descriptor.mod` plus a `path="mod/<folder name>"` line, then enable the mod in the launcher's **Playsets** tab.

## 🐛 Found a bug or have an idea?

- **Open an issue** on the repo of the mod in question. Include your game version, your other active mods, and the relevant section of `error.log` if the game complained.
- **Prefer Steam?** Leave a comment on the mod's Workshop page or message me on [Steam](https://steamcommunity.com/id/vaporjawn).
- **Want to contribute?** Pull requests are welcome. Keep changes small and focused, and mention which game version you tested on.
